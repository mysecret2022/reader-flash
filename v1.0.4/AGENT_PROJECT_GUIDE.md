# Reader-Flash 智能体项目说明文档 (Agent Project Guide) - v1.0.4

> 本文档专为后续接手的智能体与开发者编写，详尽记录了 reader-flash v1.0.4 的架构设计、界面复刻规范、已解决的问题、核心算法、测试运行指引及后续迭代路线图。

---

## 1. 版本概述 (v1.0.4)
- **核心定位**：全量 1:1 精准复刻官方经典 `reader` (即 `http://192.168.0.30:8080`) 的主书架 (`Index.vue`) 与沉浸式小说阅读界面 (`Reader.vue`) 视觉美学与排版交互体系，彻底替换原有的 VisionOS 悬浮卡片，同时完整保留现代前端技术栈（Vite 5 + Vue 3.4 + Pinia + Element Plus）、毫秒级 SSE 流式搜书以及所有近期已解决的稳定性 Bug。
- **构建环境**：Java 17+, Gradle 7.x/8.x, Node 22.x, Vite 5.2.8.
- **Git 目标分支**：`origin/dev`（禁止推向 `main` 分支）。

## 2. 界面复刻架构与规范 (对齐 192.168.0.30:8080)

### 2.1 主书架界面 (`Index.vue`)
1. **左侧固定导航栏 (`.navigation-wrapper`)**：
   - 宽度固定 `260px`，高度 `100vh`，背景色 `#f7f7f7`（暗黑主题 `#181818`），`border-box` 盒模型。
   - 标题：“阅读” (24px, 600, `#2c3e50`)，右上角版本角标 `v1.0.3` / `v1.0.4`。
   - 副标题：“清风不识字，何故乱翻书” (16px, 500, `#b1b1b1`)。
   - 搜索输入框：胶囊式圆角 `border-radius: 50px`，边框 `#e3e3e3`，前置放大镜图标。
   - 搜索设置区：
     - 搜索方式：多源搜索（支持 SSE 流式秒出）/ 单源搜索
     - 书源分组：全部分组或指定分组
     - 并发线程：4/8/12/16/24/30 并发线程
   - 探索发现：“探索书源 (发现/榜单)” 按钮
   - 管理与账户：“管理 (admin)” 下拉菜单 -> 控制台与管理后台 (`/admin`)、阅读统计、退出登录
   - 底部操作栏：🌙/☀️ 暗黑日夜主题切换按钮，GitHub 链接图标。
2. **右侧主书架展区 (`.shelf-wrapper`)**：
   - 边距 `padding: 48px`，背景 `#ffffff`（暗黑主题 `#141414`）。
   - 顶部状态与操作栏：
     - 左侧显示 “书架 (n)” 或 “搜索 (n)”（附带毫秒流式动态呼吸指示）
     - 右侧按钮：“书架”（搜索时一键返回书架）、“刷新”（刷新书架数据）、“编辑”（切换多选删除/换源管理模式）。
   - 分组标签 (`el-tabs`)：“全部”、“未分组”等。
   - 书籍卡片 (`.book`)：
     - 尺寸 `360px x 112px`，内边距 `16px 20px`，水平 Flex 布局，圆角 `4px`，微阴影与 Hover 上浮微动效。
     - 封面：`80px x 100%`，带投影与圆角。
     - 信息区：右上角未读章节数红色胶囊角标 `99+` (`#f56c6c`)；书名 (16px 加粗 `#33373d`)；作者 • 共xxx章 (12px `#969ba3`)；已读章节；最新更新章节。
     - 搜索结果卡片：同网格展示，附带 “➕ 加入书架” / “✓ 已在书架” 交互标签。
   - 移动端适配：屏幕宽度 `<= 768px` 时，左侧导航栏转为汉堡抽屉菜单，卡片宽度自适应 100%。

### 2.2 小说阅读界面 (`Reader.vue`)
1. **纸张背景与 8 套经典底色**：
   - 主题 0（经典羊皮纸）：采用官方 Base64 PNG 纹理无缝平铺 (`var(--reader-paper-bg)`)，温润古典。
   - 主题 1-7：仿古纸、护眼淡绿 (`#dcead4`)、浅天蓝 (`#d9e8fb`)、胭脂暖粉 (`#f5e4e4`)、素雅浅灰 (`#e5e6e8`)、深邃夜间黑 (`#121212`)、纯净白 (`#ffffff`)。
2. **左侧垂直悬浮工具栏 (`.tool-bar`)**：
   - 定位：`position: fixed; top: 0; left: 50%; margin-left: -(readWidth / 2 + 68)px; z-index: 2001;`
   - 7 大核心纵向按钮：
     1. `书架`：弹出书架书籍快速切换弹窗
     2. `书源`：弹出 767px 羊皮纸质感换源测速弹窗，实时显示各书源延时 `⏱ 3354ms`、`【当前使用】` 标记、最新章节，点击换源并精准对齐章节
     3. `目录`：弹出 767px 目录面板，显示总章节数、倒序/顺序、自动滚动高亮居中当前章节
     4. `设置`：弹出 767px 阅读排版偏好，支持 8 套底色切换、字体切换（系统/霞鹜文楷/思源宋体/毛笔手写）、字号大小 ➖ 18 ➕、行高、页面宽度 (640/800/960/1200px)、翻页方式
     5. `首页`：一键返回主书架
     6. `顶部`：平滑滚动到页面顶部
     7. `底部`：平滑滚动到页面底部
   - 移动端适配：在手机模式下底栏横向排布。
3. **右侧垂直悬浮快捷栏 (`.read-bar`)**：
   - 定位：`position: fixed; top: 60px; right: 50%; margin-right: -(readWidth / 2 + 52)px;`
   - 包含：🌙/☀️ 日夜模式切换、🔄 刷新本章、✈️ 全本离线下载、🎵 白噪声伴读。
4. **正文呈现与排版规范**：
   - 章节大标题：起点红 `#ed4259`，24px 加粗，居左对齐。
   - 正文段落：首行缩进 `2em`，行高 `1.8`，字号 `18px`，字体优先加载霞鹜文楷（`LXGW WenKai`），颜色 `#262626`（暗黑主题 `#abb2bf`）。
   - 底部控制：上一章、阅读进度百分比/章节指示、下一章。
   - 手机端手势交互：支持屏幕左右滑动手势翻页；点击屏幕中央 40% 区域显隐控制栏。

## 3. 已修复的核心 Bug 与算法防护

1. **换源跳回第一章 Bug (Chapter Alignment Protection)**：
   - **原因**：各书源章节划分、卷名及序号格式存在差异，换源后直接重置为 0。
   - **解决方案**：在 `switchBookSource` 中，提取原书当前章节标题，去除多余空格与“第/章/节”修饰词，通过模糊标题子串包含算法在新源目录中遍历匹配；若标题失配，则自动回退至同序号索引，杜绝跳回第一章。
2. **加入书架缺少 tocUrl 导致目录失败**：
   - 搜索结果加入书架时，自动回退设置 `tocUrl = book.tocUrl || book.bookUrl`。
3. **换源抽屉闪退与白屏问题**：
   - 统一采用标准 `el-dialog` + 自定义类名，杜绝 CSS 穿透冲突导致的闪烁。

## 4. 运行与验证指令

```bash
# 1. 编译前端并同步至 Spring Boot 资源目录
cd web
npm run sync

# 2. 编译后端可执行 Jar 包
cd ..
./gradlew assemble -x test

# 3. 运行本地极速后端
./gradlew bootRun
```
